# Downstream workbenches

Use File → Open to select a saved project, then Start.

| Bundle | Use case |
| --- | --- |
| [single](single/README.md) | One modulation profile, RxMER capture and channel estimate. |
| [multi-rxmer](multi-rxmer/README.md) | Several compatible RxMER inputs with average residual power. |
| [multi-rxmer-2](multi-rxmer-2/README.md) | All 132 channel 193 RxMER captures with flat/unity response. |
| [cl-192mhz-8mhz-notch](cl-192mhz-8mhz-notch/README.md) | Synthetic notch, baseline and channel-estimation comparisons. |

[multi-rxmer-dschan](multi-rxmer-dschan/README.md) is reserved for deferred multiple
channel-estimate playback. Original bytes, provenance and notices are preserved.
