# UI-ZOOM-01: Mouse-driven chart navigation

Replace zoom buttons in the shared TX/RX Spectrum Analyzer and Channel Estimate/
RxMER viewer with one QML mouse interaction component. Wheel zoom anchors the
frequency under the pointer; horizontal left-drag selects a range. Full Span
restores the full retained grid. Retain hover readouts; keyboard +/- and Home
provide equivalent navigation. Reject empty data and gestures outside plot axes.

`ChartNavigation.qml` owns only bounded viewport-index selection. SpectrumPlot
and MeasurementPlot forward requests to their existing parent Rust viewport
queries. Rust retains all samples, decimation and numerical interpretation.
Changing input, tap or metric resets the range through existing lifecycle rules.
Diagnostic plots without a zoom contract retain their existing behavior.

Update the coding-style skill, architecture, checklists and user guides. Verify
wheel/drag bounds, Full Span and empty-data behavior in QML tests, build the Qt
executable with retained artifacts and inspect actual dark VM plots. No core DSP
changes or broad simulation test run are required.
