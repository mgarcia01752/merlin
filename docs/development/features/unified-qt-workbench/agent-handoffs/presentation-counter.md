Source-only preparation for existing UIU-SESSION-01 C5 / REQ-UIU-07. The lead
owns the canonical [design](../design.md#uiu-session-01-c5-existing-persistent-presentation-owners),
actual presentation consumers and acceptance. This counter prerequisite does not

## Existing owner and exact reuse

Extend only `shell::RetainedResources`, its checked addition, atomic budget
admission and reservation Drop with logical UTF-16 bytes, array/object entries,
retained views and open views. These are distinct from actual Rust payload
capacities, ordered-container entries, shared roots and channel populations.
The four dedicated ceiling errors retain actual maximum/requested quantities.
No new framework, scientific metadata or public scientific/native operation is
introduced. Generic bytes-only construction admits zero in the other eight
quantities. Existing actual host storage remains covered through `size_of`.

`ApplicationSessions::desktop` uses four independently named policies from
`shell/constants.rs`: 64 MiB logical UTF-16, 1,000,000 logical entries, 128 retained
views and 32 open views. Equal numeric values with other limits do not merge
their purposes.
