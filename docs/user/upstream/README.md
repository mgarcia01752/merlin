# Upstream OFDMA

The native upstream library is being integrated into MERLIN. The
[configuration and source foundation](configuration.md) is available through
`docsis_ofdma`. The [typed transmitter](transmitter.md) also has local stage tests.
Combined waveform execution, facade imports, Python namespaces and CLI
operations follow their acceptance gates; this page does not claim those are
already available. The [official checklist](../../development/checklist.md#unified-backend-integration)
tracks delivery.
