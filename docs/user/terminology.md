# MERLIN terminology

Open this guide from **About → Terminology…** in the workbench. That menu opens
this Markdown page on GitHub in your default browser and requires internet access.
Definitions below describe the terms used in MERLIN; linked guides explain the
supported implementation and its limits.

## Workbench and signal path

| Term | Meaning |
| --- | --- |
| MERLIN | Modulation, Encoding, Reception, Link Impairments & Noise. |
| Workbench (WB) | The main diagram, configuration blocks, instruments and run controls. A saved WB contains accepted settings and embedded original input bytes. |
| DOCSIS | Data Over Cable Service Interface Specifications, the cable-access specification family. |
| PHY | Physical layer: coding, modulation, waveform transmission and reception. |
| CMTS | Cable Modem Termination System. MERLIN simulates supported downstream PHY functions for one OFDM channel. |
| CM | Cable modem. PNM input files represent measurements collected by a modem; MERLIN does not control or capture from a modem. |
| Source / PRBS-TX | Original traffic before encoding. The Source stage uses the accepted PRBS-TX settings: generated PRBS15, or exact file bits with optional PRBS fill. It is not the NCP/PLC control source. |
| PRBS15 | A repeatable pseudorandom binary sequence generated by a 15-bit shift register. Its sequence period is 32,767 bits. It supplies test traffic and is separate from PHY scrambling. |
| Transmitter (TX) | Encodes source bits, maps modulation cells and produces an OFDM waveform. |
| Channel | Applies the configured response and noise between transmitter and receiver. |
| Receiver (RX) | Processes received samples, recovers signaling and decodes payloads. |
| PRBS-RX / comparison | Independently compares decoded payload bits with the original accepted source. It does not feed expected bits into decoding. |
| Test point (TP) | An inspectable boundary between processing stages. A selected instrument reads retained data from that boundary. |
| Snapshot | A bounded retained observation, not the entire history of a simulation. A missing snapshot is not automatically a processing failure. |

See the [workbench](workbench.md), [source editor](source-input.md) and
[transmitter stages](transmitter-workbench.md).

## OFDM and waveform terms

| Term | Meaning |
| --- | --- |
| OFDM | Orthogonal Frequency Division Multiplexing: many orthogonal subcarriers transmitted together. |
| Subcarrier | One frequency position in the OFDM grid. Depending on configuration and time, it can carry data, control, a pilot or no signal. |
| Cell | One modulation value associated with a subcarrier during one OFDM symbol. Cells are reordered by interleaving. A data cell holds one QAM symbol; it is not an entire OFDM symbol or a codeword. |
| OFDM symbol | One time step containing the subcarriers together. Its transmitted waveform includes the useful FFT interval and the configured cyclic prefix/window treatment. |
| I/Q | In-phase and quadrature components: the real and imaginary coordinates of a complex sample or modulation value. |
| Baseband | A frequency representation centered around zero, before RF upconversion. |
| Complex baseband | Baseband represented as I/Q. It retains phase and distinguishes positive and negative frequency offsets. “Complex” describes the representation, not another frequency band. |
| Sample rate | Number of time-domain samples per second, shown in MS/s for millions of samples per second. |
| FFT / IFFT | Fast Fourier Transform / inverse FFT. The receiver converts time samples to subcarrier values; the transmitter performs the inverse operation. |
| Cyclic prefix (CP) | A cyclic extension preceding the useful symbol interval, helping accommodate delayed channel energy. |
| Roll-off period (RP) | The transition interval used by the transmit window to smooth symbol boundaries. |
| Flat guard time | In MERLIN's timing panel, the cyclic-prefix interval remaining after the configured roll-off interval. It is an ideal timing budget, not guaranteed echo protection. |
| Pilot | A known reference signal used for tasks such as tracking and channel estimation. Continuous and scattered pilots occupy different patterns. |
| Interleaving | Reorders bits or cells to spread localized impairments. Bit interleaving and time/frequency cell interleaving operate on different objects. |

See [transmission settings](transmission.md), [waveform stages](waveform/README.md)
and the [Spectrum Analyzer](spectrum-analyzer.md).

## QAM and decisions

| Term | Meaning |
| --- | --- |
| QAM | Quadrature Amplitude Modulation: information represented by a set of I/Q constellation points. |
| QAM order | Number of available constellation points. 256-QAM carries 8 coded bits per data cell; 4096-QAM carries 12. These are coded bits, not net payload bits after FEC overhead. |
| QAM symbol | One selected constellation value. Distinguish it from an OFDM symbol, which contains many subcarrier values. |
| Cell label | An integer identifying the selected QAM point before mapping to I/Q. For 256-QAM, labels range from 0 through 255. The label is not a subcarrier index. A separate label snapshot is unavailable on the current profile-based TX path; mapped I/Q remains inspectable. |
| Constellation | A plot of I/Q values. Ideal modulation points form the reference pattern; noise and distortion can displace received points. |
| Decision boundary | A dividing line between regions assigned to neighboring constellation points by the slicer. Crossing one can change the hard symbol decision. |
| QAM slicer / hard decision | Selects a constellation label from a received I/Q value. It differs from the soft information supplied to FEC decoding. |
| LLR | Log-likelihood ratio: soft evidence for a bit being zero versus one. In MERLIN's LLR view, positive favors zero and negative favors one; larger magnitude indicates stronger evidence under the model. |
| Data / NCP colors | Mixed TX QAM plots use green squares for data and red circles for NCP, with a legend. These colors indicate roles, not success/error status. |
| Filler | Explicit non-payload cells used where the transport requires them. Mixed TX plots show retained filler as amber diamonds. Missing history is separate and is not plotted as zero-valued I/Q. |

“Cell words,” “bits per cell” and “output data cells” are DOCSIS PHY terminology:
CM-SP-PHYv3.1-I20-230419, §7.5.5, Table 31, PDF page 120. This terminology was
checked against the repository's text extract, not a rendered PDF.
See [QAM processing](qam-processing/README.md) and [receiver instruments](receiver-workbench.md).

## Configuration, signaling and measurements

| Term | Meaning |
| --- | --- |
| OCD | OFDM Channel Descriptor: common channel configuration carried in downstream signaling. |
| DPD | Downstream Profile Descriptor: profile-specific modulation assignments. The DPD input editor imports modulation-profile PNM data; the TX message inspector shows actual generated DPD signaling packets. They are different file/message representations. |
| Profile | A set of modulation assignments over the channel's subcarriers. An imported profile is not automatically supported for a live run. |
| PLC | Physical Link Channel: protected signaling used to acquire and configure downstream OFDM reception. |
| NCP | Next Codeword Pointer: control signaling that identifies codeword placement and related transport information. NCP is distinct from payload data. |
| TLV | Type-Length-Value: a tagged field containing its type, value length and value bytes. Decoded child fields in the inspector are not necessarily nested TLVs. |
| PNM | Proactive Network Maintenance. MERLIN uses supported existing PNM captures as simulation inputs. |
| RxMER | Receive Modulation Error Ratio: per-subcarrier signal-to-modulation-error power ratio, commonly expressed in dB. MERLIN uses it to model residual error power; it does not reconstruct measured I/Q from RxMER. |
| Channel estimate H | Complex frequency response across subcarriers. Flat/unity H = 1 + 0i means no gain/phase change; H = 0 + 0i would suppress the signal. |
| Receiver estimate H-hat | Channel response estimated from received pilots, distinct from the supplied reference H. |
| Equalization | Applies a correction based on channel response to reduce its effect on received constellation points. |
| Echo | A delayed copy of the signal. An impulse-response peak is not automatically a uniquely identified physical reflector. |
| Velocity factor (VF) | Signal propagation speed in the cable divided by the speed of light. Reflector-distance estimates assume an out-and-back path. |

See [measurement inputs](channel-measurements.md), [TLV inspection](transmitter-workbench.md)
and [receiver channel estimation](receiver-estimation/README.md).

## Coding, results and analyzer units

| Term | Meaning |
| --- | --- |
| FEC | Forward Error Correction: adds redundancy so a receiver can detect/correct errors. |
| BCH / LDPC | Bose–Chaudhuri–Hocquenghem / Low-Density Parity-Check coding. MERLIN uses both in the supported payload coding chain. |
| Codeword | A block produced by an error-correcting code. One codeword can span many modulation cells and multiple OFDM symbols. |
| BER | Bit Error Rate: compared bit errors divided by compared bits. With no compared bits, BER is unavailable, not zero. |
| Decoder iterations | Repeated LDPC decoding steps. More iterations mean more decoder work; reaching a limit does not by itself describe every BCH or payload outcome. |
| Spectrum Analyzer (SA) | Displays power versus frequency for a selected test point. TX and RX instruments use distinct retained boundaries. |
| PSD | Power Spectral Density: power per unit frequency. MERLIN's time-sample SA uses normalized dB/Hz, not calibrated RF dBm or dBmV. |
| ENBW | Equivalent Noise Bandwidth: the effective noise bandwidth of the FFT window. It differs from the frequency spacing between FFT bins. |
| Capture frequency mapping | Labels baseband bins using the capture's frequency origin. It does not upconvert the simulated signal. |
| Observation duration | Source observation interval configured in Receiver / Run. Acquisition and completion/drain can add processing beyond that interval. |

See [FEC](fec-codec.md), [run/results](closed-loop-workbench.md) and the
[Spectrum Analyzer guide](spectrum-analyzer.md). Return to the
[documentation index](../README.md).
